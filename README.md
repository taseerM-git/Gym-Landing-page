# Ironyard Gym: Landing Page

A responsive one-page landing page built with React, Vite and Tailwind CSS. 
The page has one goal: get visitors to book a free day pass.

# Features

- Hero section with a clear call to action
- Stats cards (classes, coaches, opening hours)
- Three pricing plans (Starter, Strength, Coached)
- Contact form with name and email validation
- Fully responsive on mobile, tablet and desktop
- Light and dark mode based on system setting

# Tech stack

- React 18
- Vite 5
- Tailwind CSS 3
